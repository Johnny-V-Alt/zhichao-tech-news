# 图文正文与阅读排版验收（2026-11-27，北京时间）

## 直接复用

- Trafilatura 2.4.0 原生 HTML 输出，开启 include_images、include_formatting、include_links；继续保留纯文本供搜索与分类使用。
- DOMPurify 3.5.0 原生 HTML 清洗引擎。阅读器限定正文标签、属性、公开文章链接及本机缓存图片；移除脚本、嵌入、事件属性与来源样式。
- github-markdown-css 5.9.0 的 github-markdown-light.css 原文件直接导入。独立本地 CSS 调整中文间距、字号继承、图片最大高度和手机布局。
- jsdom 31.0.1 / @types/jsdom 30.0.0 仅用于开发测试；没有接入 Readability。
- 原始许可证与版本记录见 THIRD_PARTY_NOTICES.md、UPSTREAM.json 及 vendor 对应目录。

## 存储与补全

图文单独保存到 content_article_documents，并与当前文章指纹关联。纯文本来源再次采集时不会清掉图文；文章实际内容改变时旧图文失效，进入重新补全流程。图文格式升级不单独伪造新闻新版本，不改写原始发布日期。既有全文也会重新进入 Huey 持久队列；手动重试缺图记录有更高优先级。

配图按内容哈希缓存至 data/article-images，图片 API 仅读取本地缓存，不抓取任意请求地址。下载限制与失败占位规则见 README。原站没有正文配图的文章不制造图片；访问受限或未缓存成功的图片保留提示及原文入口。

## 运行约束

自动补全需要网站服务保持运行、自动采集开启，历史文章逐批处理。原站权限、网络或提取效果仍可能限制图片获取；可在管理页“图文补全与重试”重试。此次没有调用模型，也不需要模型密钥。运行数据库、缓存图片、管理码和日志不随 GitHub 源码发布。
