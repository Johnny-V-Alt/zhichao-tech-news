# 最新新闻图文补全修复（2026-11-28）

## 原因与变更

此前只验证了已完成图文补全的历史样本，未覆盖首页最新文章。旧队列把历史纯文本全文排在新摘要前面，新文章长期只显示来源摘要。现在以原始发布时间决定 Huey 优先级，并通过 Huey 原生 API 更新持久队列中已有任务的优先级，保留任务 ID 和重试计数。未知日期保持未知，不使用采集时间冒充发布日期；人工重试缺图仍优先。

另有旧任务的 Windows 进程号被无关程序复用，导致调度器一直认为任务运行中。现在同时检查进程类型、启动时间、runner 路径及任务 ID；新任务记录启动 ticks。失效任务恢复为 interrupted，不终止无关程序。

阅读页将配图高度限制为 min(60vh, 520px)，段落间距调整为 1em。PWA 更新检查缩短至一分钟，阅读页发现更新后自动应用，管理页面保留原有更新提示。
